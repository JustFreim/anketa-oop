# Обработчик анкет на классах

Программа читает файл с анкетами двух типов (студент и преподаватель),
проверяет данные, печатает общую таблицу принятых анкет, список брака
и статистику, а результаты сохраняет в файлы.

## Запуск

```
python main.py
```

Нужен Python 3.10 или новее. Сторонних библиотек не требуется.

## Формат входного файла

Файл `data/anketa.txt`. Одна строка - одна анкета, пять полей через
точку с запятой:

```
тип ; ФИО ; почта ; телефон ; группа или кафедра
```

Тип: `s` - студент (последнее поле - группа), `t` - преподаватель
(последнее поле - кафедра). Пустые строки пропускаются.

## Структура проекта

```
people.py        AnketaError, Person, Student, Teacher, parse_line
registry.py      Registry: журнал, чтение файла, статистика, сохранение
main.py          запуск и вывод таблицы
data/anketa.txt  пример входных данных
test_people.py   тесты к people.py
test_registry.py тесты к registry.py
razminka/        учебные модули calc.py, wordcount.py и тесты к ним
```

## Как устроены классы

- `Person` - общая часть: ФИО, почта, телефон и проверки в `__init__`.
  При плохих данных бросает `AnketaError`, объект не создаётся.
- `Student` и `Teacher` наследуют `Person`, добавляют группу и кафедру.
- `Registry` содержит список анкет и список брака (композиция).

## Результат работы

Принятые анкеты сохраняются в `ok.txt`, бракованные с причинами - в
`errors.txt`. Оба файла создаются заново при каждом запуске.

## Тесты

```
pip install pytest
python -m pytest -q
```

Запускать из корня проекта и именно так (`python -m pytest`, а не просто
`pytest`), иначе тесты не найдут модули проекта.
